# 🔍 DocSearch - High Performance Document Search Engine

A secure and high-performance document search engine built using Spring Boot, Apache Lucene, PostgreSQL, and JWT Authentication. It allows users to upload, search, preview, bookmark, download, and manage documents with lightning-fast full-text search.

---

# 🚀 Features

## 🔐 Authentication & Security
- JWT Authentication
- Spring Security
- Role-Based Access Control (Admin/User)
- Secure Login & Registration
- Password Encryption (BCrypt)

## 📄 Document Management
- Upload PDF, DOCX, and TXT files
- Preview Documents
- Download Documents
- Delete Documents
- Automatic Lucene Indexing

## 🔍 Full-Text Search
- Apache Lucene Search Engine
- Fast Keyword Search
- Relevance-Based Ranking
- Search History
- Recent Searches

## ⭐ Bookmarks
- Add Bookmark
- Remove Bookmark
- View Saved Documents

## 👤 User Dashboard
- My Documents
- Search Statistics
- Bookmark Statistics
- Recent Searches

## 👨‍💼 Admin Features
- View All Users
- Delete Users
- Delete Admin (Last Admin Protection)
- Manage Documents

# ▶️ Run the Project

## Clone Repository

```bash
git clone https://github.com/Kalyani132004/DocSearch.git
```

## Backend

```bash
cd backend
mvn clean install
mvn spring-boot:run
```

Open your browser:

```
http://localhost:8080
```
